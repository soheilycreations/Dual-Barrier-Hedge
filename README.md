# Dual-Barrier Hedge Bot — LIVE

A sleek, professional trading dashboard for the Deriv API. This bot implements a dual-barrier hedging strategy with built-in risk management and real-time market data visualization.

## 🚀 Features

- **Real-time Data**: Connects directly to Deriv WebSocket for live tick updates.
- **Dual-Barrier Strategy**: Automatically places Higher/Lower contracts based on Bollinger Band breakouts.
- **Risk Management**:
  - Automatic Stop Loss (SL)
  - Target Take Profit (TP)
  - Martingale Logic (2.1x)
- **Sleek UI**: Cyberpunk-inspired dark theme with responsive KPI displays.

## 🛠️ Setup & Usage

1. **Get an API Token**:
   - Go to [app.deriv.com](https://app.deriv.com)
   - Navigate to **Account Settings** -> **Security & Safety** -> **API Token**.
   - Create a token with **Read** and **Trade** permissions.
2. **Open the Dashboard**:
   - Simply open `index.html` in any modern browser or deploy to a static hosting service.
3. **Connect**:
   - Paste your API Token into the connection panel.
   - Click **Connect**.
   - Once connected, click **Start Bot** to begin automated trading.
